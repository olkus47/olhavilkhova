## 🚀 Features & Highlights

- **Interaktiver Canvas-Hintergrund:** Physikbasierte Partikel- und Konstellations-Animation mit dynamischer Maus-Interaktion über die HTML5 Canvas API.
- **Scramble-Text-Effekt:** Dekodierungs-Animation für den Namen im Hero-Bereich via `TextScramble` JavaScript-Klasse.
- **3D-Foto-Flip-Carousel:** Interaktive 3D-Kartenrotation zum Durchwechseln persönlicher Profilbilder.
- **Scroll-Reveal-Animationen:** Performantes Einblenden von Sektionen über die moderne `IntersectionObserver`-API.
- **Mobile-First & Responsive:** Vollständig responsives Menü und Layout für alle Bildschirmgrössen (Desktop, Tablet, Mobile).
- **Modulare Architektur:** Klare Trennung von Struktur (`index.html`), Design (`style.css`) und Logik (`script.js`).

## 💻 Lokale Entwicklung

Da das Projekt mit nativem HTML, CSS und JavaScript umgesetzt ist, wird kein komplexer Build-Schritt benötigt.

### Option 1: Live Server (VS Code)
1. Repository in VS Code öffnen.
2. Die Erweiterung **Live Server** installieren.
3. Rechtsklick auf `index.html` ➔ **«Open with Live Server»**.

### Option 2: Lokaler Python-Server
```bash
# Im Projektordner ausführen:
python -m http.server 3000
```
Anschliessend im Browser `http://localhost:3000` aufrufen.
